# 🎓 AcademIQ - Academic Management System

AcademIQ is a full-stack academic management platform built for coaching institutes, tuition centers, and educational organizations. The system provides dedicated Teacher and Student portals with secure Role-Based Access Control (RBAC), enabling efficient management of classes, students, attendance, marks, assignments, fees, and notifications.
