# 🎓 AcademIQ – The IQ Behind Your Classroom

A web-based academic management system that digitizes and centralizes core institutional operations.

---

## 📌 Overview

**Problem:** Institutions rely on manual systems (registers, spreadsheets) → inefficient, inconsistent, no real-time insights.

**Solution:** A centralized platform for managing students, attendance, performance, assignments, and fees.

---

## ⚙️ Core Features

* **Student Management** – Centralized profiles with credentials
* **Attendance Tracking** – Daily logs with history
* **Marks & Performance** – Subject-wise tracking + insights
* **Fee Management** – Payments, dues, history
* **Assignments** – Create, assign, notify
* **Notifications** – Broadcast alerts instantly

---

## 🛠️ Tech Stack

* **Frontend:** Next.js, TypeScript, Tailwind CSS
* **Backend:** Node.js, Next.js API Routes
* **Database:** MongoDB + Mongoose
* **Security:** JWT, bcrypt, RBAC
* **Tools:** Git, GitHub, Vercel

---

## 🧱 Architecture

Modular **MVC architecture** with:

* Components & Hooks (Frontend)
* Controllers & Services (Backend)
* MongoDB Models (Data Layer)
* Utils & Middleware (Validation + Security)
